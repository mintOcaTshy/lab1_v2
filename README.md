# Лабораторна робота №1

**Тема:** Реалізація структури даних ArrayList (динамічний масив) мовою C.
**Виконала:** студентка групи КБ-31 Марініна Соф'я

## Опис проєкту
Цей репозиторій містить базову реалізацію динамічного масиву цілих чисел. 
Підтримуються такі операції:
- ініціалізація та очищення пам'яті
- додавання елементів у кінець списку
- вставка елемента за індексом
- Видалення елемента зі зсувом
- отримання та заміна значення за індексом

## Збирання та запуск
Для збирання програми використовується утиліта - **make**. 
Команда для компіляції - `make`
Команда для очищення - `make clean`
